# Public-tree manifest for the VOWP repository.
#
# scripts/audit/public-tree-check.sh enforces this file and
# scripts/audit/squash-for-public.sh uses it to build public-main. It stays in
# the private tree; it is itself pruned from the public branch.
#
# Each non-comment line is one entry:
#   allow <path>    a top-level file or directory permitted in public-main
#   prune <path>    an internal path excluded from public-main; a trailing
#                   slash covers the directory and everything below it
#   require <path>  a product path that must exist in public-main; a trailing
#                   slash means a non-empty directory
#
# Keep the list aligned with the owner's public-tree decision. Add a reason to
# the commit message when a path moves between sections.
