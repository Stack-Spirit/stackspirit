# StackSpirit 0.6.1

Patch release on top of `0.6.0` fixing PyPI PEP 639 wheel metadata and updating package repository URLs to `Stack-Spirit/stackspirit`.

## What changed

- **PyPI wheel metadata:** use PEP 639 relative `License-File: LICENSE` path and enable verbose PyPI publish logging in `.github/workflows/release.yml`.
- **Packaging URLs:** point npm and PyPI metadata at `https://github.com/Stack-Spirit/stackspirit`.
- **Desktop UI:** show `waiting for verification` instead of `unknown` for reviewing jobs with no active worker session.
- **Public readiness:** add history-aware secret/privacy scan and release documentation updates.

## Install

```sh
npx stackspirit@0.6.1 --version
uvx stackspirit==0.6.1 --version
```
