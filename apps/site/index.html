Quickstart

From zero to a Home in minutes.

The software is free and needs no account. Install it on the machine that will stay on, then connect from the desktop, Web App, CLI or any MCP client.

Run the npm launcher with Node.js 22 or newer. It fetches the native binary for your platform.

$ npx -y stackspirit

On the Home, stackspirit doctor checks the node, database and harnesses before you start.

Prefer Python? The PyPI launcher installs the same native StackSpirit binary with uv.

$ uvx stackspirit

The CLI is the same binary as the npm package, so flags and fixtures match across both launchers.

Expose the Home as a stdio MCP server. Add it to Claude Code, Codex, OpenCode or any MCP client.

$ npx -y stackspirit mcp

MCP tools read and write the same Home, so your harness sees the real job graph and session log.

Security

Your machine. Your keys. Your call.

StackSpirit is built around an account-free local mode. Your connection details stay on your device, and the cloud is optional.

Account-free by default

Connect a machine over SSH without creating an account. A free StackSpirit account is only needed for the Web App from another device or a managed Home.

SSH with pinned host keys

The desktop app verifies the server fingerprint before installing its own key. StackSpirit never stores raw SSH private keys in the cloud.

Secrets stay by name

Provider keys live in your OS keychain or in the secret vault on the Home. The AI sees secret names and metadata, never the values.

Read the full model in SECURITY.md. This site loads no third-party trackers and no analytics.

FAQ

Questions, answered plainly.

Is StackSpirit really free?

Yes. The software is MIT-licensed and free forever. You can connect your own VPS, spare laptop or home server at no software cost. Managed Always-On Homes are optional paid hardware, not a software license.

Do I need a StackSpirit account?

No for local and SSH mode. An optional free account is only needed when you want to reach a Home from the Web App on another device, use cross-device sign-in, or run a managed Always-On Home.

What counts as an always-on machine?

Any Linux machine you can reach over SSH: a VPS, a spare laptop, a home server or a small Mini PC. The Home runs the supervisor and keeps the session log; the desktop app is the cockpit.

Which harnesses work with StackSpirit?

Claude Code, Codex, OpenCode, Antigravity, T3 Code and any MCP or CLI harness. StackSpirit sits underneath the harness instead of replacing it, so you can switch tools without moving machines.

Are managed Homes shared with other customers?

No. Each Home is a dedicated Contabo VPS with its own credentials and firewall. The price is Contabo’s regular monthly rate plus a transparent 20% StackSpirit markup.

Are backups included with a managed Home?

No. Off-site encrypted backups to Cloudflare R2 are an optional add-on and off by default. When enabled, they cover your ~/.stackspirit data, sessions and configs, off the machine provider. You can turn them on at checkout.

Is there a free trial for managed Homes?

No. Managed Homes are provisioned on demand and require a verified payment method up front. The free path is to run StackSpirit on hardware you already own.

Where do my keys and data live?

On your machine. The StackSpirit database, session logs and project state stay on the Home you control. Provider secrets stay in your OS keychain or the secret vault on the Home, and the AI only sees names and metadata.
