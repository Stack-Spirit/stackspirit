HARNESSES Zero token billing · One clear distinction

OpenCode by default. Any coding CLI underneath.

StackSpirit never resells tokens or extracts OAuth credentials. Connect your providers inside OpenCode (default), embed official ACP harnesses for both Orchestrators + Workers, or run subscription CLIs like Claude Code and Gemini CLI cleanly as stock CLI Workers in a live terminal view.

ZERO TUNNELS One-click Desktop Connect

Sign in once from your Mac. Both machines stay connected.

Click Connect in the StackSpirit Desktop app to install and authorize a CLI harness on both your local Mac and your Always-On Machine. StackSpirit opens a short-lived, invisible loopback port-forward so the provider’s OAuth callback lands directly on your Home — then closes it automatically. Provider credentials never touch StackSpirit Cloud. 

# ~/.stackspirit/harnesses/my-cli.toml
id = "my-cli"
name = "My Custom Agent CLI"
binary = "my-agent"
protocol = "acp"        # or "cli-pty" for workers-only
auth_cmd = "my-agent login"
