HARNESSES Overarching engine + bring-your-own CLI

OpenCode by default. Any coding CLI underneath.

StackSpirit ships with OpenCode as its default engine (bring your own DeepSeek, OpenRouter, Anthropic API, OpenAI API, or Ollama keys), and lets you connect Claude Code, Codex, Gemini CLI, Antigravity, Cursor CLI, Aider, Goose, or any custom CLI through a single declarative manifest.

ZERO TUNNELS One-click Desktop Connect

Sign in once from your Mac. Both machines stay connected.

Click Connect in the StackSpirit Desktop app to install and authorize a CLI harness on both your local Mac and your Always-On Home. StackSpirit opens a short-lived, invisible loopback port-forward so the provider’s OAuth callback lands directly on your VPS — then closes it automatically. Provider tokens never touch StackSpirit Cloud. 

# ~/.stackspirit/harnesses/my-cli.toml
id = "my-cli"
name = "My Custom Agent CLI"
binary = "my-agent"
protocol = "acp"
auth_cmd = "my-agent login"
