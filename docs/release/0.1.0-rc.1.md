# VOWP 0.1.0-rc.1 (internal)

This was an internal release candidate built in the private repository. It was
never tagged, published or deployed, and it is not part of the public release
history.

The first public release is **[0.1.0](0.1.0.md)**; its install options,
verification results and known limitations supersede anything that was written
for this candidate.

## Open defects and gaps

See [0.1.0 — Known limitations](0.1.0.md#known-limitations). The supervisor
dogfood defects D1–D7 were open at the candidate; the public release notes
disclose the ones that still apply to 0.1.0.
