# scripts/audit/allowlist.txt
#
# Each non-comment line is: rule|path|matched-value|reason
#   rule          one of ipv4, home_path, email, token, private_host, ssh_host,
#                 ssh_target, secret_path, large_blob
#   path          a repo-relative file path, or * for a value that is safe anywhere
#   matched-value the exact text the scanner matched (never a secret)
#   reason        why this finding is safe; must not be empty
#
# The scanner rejects a malformed entry or an empty reason. Keep entries
# narrow: an exact path is better than *. Never add a real secret, a real
# account name, a private hostname or a real e-mail address here.
#
# Loopback is an IPv4 address but names the local machine, not a private host.
ipv4|*|127.0.0.1|Loopback address, public by definition and used in the security docs.
# 0.0.0.0 is the wildcard bind address, not a host or an owner address.
ipv4|*|0.0.0.0|Wildcard bind address in a test fixture and the v0.2 design example.
# RFC 5737 TEST-NET-1 is reserved for documentation and cannot name a real host.

ipv4|crates/vowp-agent/tests/transport.rs|192.0.2.10|RFC 5737 TEST-NET-1 address in a non-loopback bind refusal test.
ipv4|crates/vowp-protocol/tests/config.rs|192.0.2.10|RFC 5737 TEST-NET-1 address in a non-loopback listen validation test.
